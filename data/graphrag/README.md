# WorkGraph GraphRAG Synthetic Knowledge Dataset

Synthetic, non-sensitive data for the WorkGraph GraphRAG upgrade.

Contents:
- employees/: natural-language employee profiles and experience
- projects/: project descriptions and requirements
- roles/: target/current role descriptions
- courses.csv: sample learning-resource catalog

These files are intended for local development and demonstrations. Course URLs are platform home/search placeholders, not claims about specific current course availability.
